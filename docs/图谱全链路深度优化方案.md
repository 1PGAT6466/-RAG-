# 图谱全链路深度优化方案

> 版本 v1.0（2026-08-26）
> 依据：真实数据诊断（entity_extractor + relation_builder + rag.db 实况）

## 〇、诊断结论（真实数据）

| 维度 | 实况 | 问题 |
|------|------|------|
| 实体类型 | standard 467 / material 15 / process 9 / connector 6 / param 5 | 严重失衡，standard 碎片挤压有价值实体 |
| 关系类型 | cooccur 4225(99%) / compatible_process 29 / spec 12 / uses_standard 0 | 语义边几乎缺失 |
| cooccur 权重 | 3851 条 weight=1（91%） | 单次共现噪声主导图谱 |
| 别名 | 481/502 实体无别名（96%） | 同义词无法归并 |
| uses_standard | 0 条（同句共现 too 严格） | 材料→标准核心知识全缺 |
| 数据完整性 | 0 孤儿实体 / 0 孤儿关系 | ✅ 好 |

## 一、四项优化（用户全选）

### 1. 补齐 uses_standard 边（材料→采用标准）
- 根因：同句共现 = 0，同 chunk = 82 但 65 条错误（联到紧固件标准）
- 修复：**「材料领域过滤」** —— 只联 `standard_domain='材料'` 的标准号，82→8 条高质量边
- 已知瑕疵：GB/T 6170/6171（螺母）被误分到材料领域，属 standard_domain 分类问题，不阻断
- 实施：改 `_build_uses_standard_edges` 加 domain 过滤；补跑存量

### 2. 实体抽取覆盖提升
- 现状：connector 6（词典12个但只命中6）/ material 15 / process 9 / param 5
- 修复：
  - 扩充 CONNECTOR_DICT（补充更多工业连接器系列）
  - 扩充 MATERIAL_DICT（补充 POM/PPO/PC/PU/SUS/AL 等）
  - param 增加更多工业参数（介电常数、绝缘电阻、耐压、爬电距离等）
  - 注意：扩充需谨慎，避免噪声（表格里的数字误伤）

### 3. cooccur 噪声治理
- 现状：delete 掉低权重边有风险（不可逆）
- 修复（展示/检索层，不删数据）：
  - 前端 draw() 已按 cooccur 用 0.04 极淡透明度（已有）
  - 增强：cooccur 边 alpha 按 weight 归一化（weight 越高越实）
  - 检索层 graph_recall 可对高权重 cooccur 加权

### 4. 实体同义归并/别名
- 现状：481 无别名
- 修复：建别名字典 ALIAS_MAP，在 normalize_entities 里自动补别名
  - 全称/缩写：GB→国标、镀金→金镀层 等
  - 材料常见别名：铜合金→紫铜/黄铜、不锈钢→SUS304
  - 补跑：给存量实体批量补别名

## 二、实施顺序
1. uses_standard 边补建（数据层，1 个函数 + 补跑脚本）
2. 实体抽取覆盖（entity_extractor 词典扩充）
3. cooccur 权重归一化（前端 draw + graph_recall）
4. 别名归并（normalize_entities + 补跑）
